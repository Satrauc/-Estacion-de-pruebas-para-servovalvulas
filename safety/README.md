# Seguridad

Índice operativo de documentos de seguridad. La fuente técnica de seguridad es [`docs/04-safety/safety-plan.md`](../docs/04-safety/safety-plan.md), junto con los procedimientos de prueba específicos que se aprueben.

No se debe energizar ni conectar una servoválvula real solo con base en este repositorio. Antes de una prueba real, completar y revisar la evaluación de riesgos, límites eléctricos, procedimiento, E-Stop, inhibición hardware, respuesta a fallos, instrumentación y condiciones de parada. La aprobación corresponde al responsable técnico competente del proyecto.
