# Architecture Decision Records (ADR)

Las decisiones que afecten arquitectura, interfaces, seguridad, coste/viabilidad o restricciones se registran aquí. Los ADR aceptados son históricos e inmutables: si una decisión cambia, crear un ADR nuevo que la reemplace y enlazar ambos.

## Estados

`Propuesto` → `Aceptado` o `Rechazado` → `Reemplazado` cuando corresponda.

```markdown
# ADR-NNNN: Título
- Estado: Propuesto
- Fecha: AAAA-MM-DD
- Decisores: por asignar

## Contexto
## Decisión
## Alternativas consideradas
## Consecuencias
## Evidencia y requisitos relacionados
## Revisión / decisión que reemplaza (si aplica)
```
